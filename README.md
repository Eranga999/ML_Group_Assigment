# Sri Lankan Hotel Booking Cancellation Prediction Project 🏨📊

A complete machine learning assignment project focused on predicting hotel booking cancellations using real booking data and comparing multiple classification models for practical hospitality decision-making.

## 🌟 Project Overview
This project was developed to help the Sri Lankan hotel industry understand and anticipate booking cancellations. By using historical booking records, the team built predictive models that can identify whether a reservation is likely to be canceled. The goal is to support better resource planning, staff allocation, inventory control, and revenue management in hotels.

The analysis is not only academic—it reflects a real business problem in the hospitality sector where cancellations directly affect occupancy, service quality, and financial planning.

---

## 🎯 Objective
The main objectives of this project are to:
- Predict whether a hotel booking will be canceled.
- Compare several machine learning classifiers.
- Identify the most effective model for this problem.
- Present the workflow in a clear, reproducible format for learning and demonstration.

---

## 🧠 What This Project Includes
This repository contains four individual machine learning notebooks, each focusing on a different algorithm:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest

Each notebook explores data preprocessing, model training, performance evaluation, and visualization of the results.

---

## 📊 Dataset
- Source: Hotel Booking Demand Dataset from Kaggle
- Original size: 119,390 booking records
- Features: 32 variables including booking lead time, hotel type, market segment, room type, deposit type, customer type, and arrival details
- Context: Adapted for a hospitality and tourism scenario relevant to Sri Lankan hotel operations

This dataset is ideal for understanding how customer booking behavior influences cancellation likelihood.

## 🏗️ Workflow
The project follows a standard machine learning pipeline:
1. Load and inspect the dataset
2. Clean and preprocess the data
3. Encode categorical variables
4. Split data into training and testing sets
5. Train multiple classification models
6. Evaluate model performance using metrics such as accuracy, precision, recall, F1-score, and ROC-AUC
7. Compare results and summarize the best approach

## 📈 Model Comparison Summary
The project compares several supervised learning approaches for booking cancellation prediction:

| Model | Focus | Role in Project |
|---|---|---|
| Logistic Regression | Simple baseline classifier | Good for understanding feature impact and baseline performance |
| KNN | Distance-based learner | Useful for pattern recognition in booking behavior |
| Decision Tree | Rule-based model | Helps interpret decision logic clearly |
| Random Forest | Ensemble model | Stronger performance and better generalization for complex patterns |

The notebooks in this repository include detailed experiments, model tuning, and evaluation outputs for each method.
